# 数据规范

## 准星代码格式

分号分隔的「键;值」文本，示例：

```
0;s;1;P;c;5;h;0;0l;4;0o;2;0a;1;0f;0;1b;0;S;c;4;o;1
```

- 开头 `0` 为版本号
- `P` / `A` / `S` 分别为主准星 / 开镜 / 狙击镜段
- 仅解析 `P` 段用于预览；忽略 `m`/`f` 动态误差

### 常用键

| 键 | 含义 |
| --- | --- |
| `c` | 颜色枚举：0 白 · 1 绿 · 2 黄 · 3 黄绿 · 4 青绿 · 5 青 · 6 粉 · 7 红 · 8 自定义 |
| `u` | 自定义色，格式 `RRGGBBAA`（如 `D099E2FF`） |
| `h` | 描边开关（0/1） |
| `o` | 描边不透明度（0-1） |
| `d` | 中心点开关（0/1） |
| `z` | 中心点粗细 |
| `0l`/`0t`/`0o`/`0a` | 内线 长度/粗细/偏移/透明度 |
| `1l`/`1t`/`1o`/`1a` | 外线 长度/粗细/偏移/透明度 |
| `0b`/`1b` | 内线/外线 开关（0/1） |

> 颜色枚举依据真实选手校正：TenZ 的 `c;5` 为青色。

## 数据文件 schema（`data/crosshairs.json`）

```json
{
  "updatedAt": "YYYY-MM-DD",
  "community": [
    { "id": "dot", "name": "纯点准星", "tags": ["点", "精确"], "code": "0;P;..." }
  ],
  "pros": [
    { "id": "tenz", "name": "TenZ", "cn": "中文名（可选）", "team": "Sentinels", "code": "0;P;..." }
  ]
}
```

- `community`：社区准星，`tags` 为搜索用标签
- `pros`：职业选手，`name` 为 ID，`cn`/`team` 可选，显示在准星下方
