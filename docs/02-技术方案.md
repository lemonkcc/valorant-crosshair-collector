# 技术方案

## 技术栈

- **Electron**：Windows 桌面外壳
- **原生 HTML/CSS/JS**：界面（不引入 React/Vite，保持轻量、稳定、易维护）
- **electron-builder**：打包 Windows 安装包（.exe）
- **JSON 文件**：准星数据（`data/crosshairs.json`）

## 架构与目录结构

```
main.js            Electron 主进程：创建窗口
preload.js         桥接层：读取内置 JSON 数据、写入剪贴板（contextBridge）
renderer/
  index.html       界面结构
  styles.css       淡黄色样式
  app.js           交互：栏目切换、搜索、卡片渲染、复制
  crosshair.js     准星代码解析 + Canvas 绘制预览
data/
  crosshairs.json  社区 + 职业选手准星数据
docs/              项目标准文档
开发日志/           每日开发日志
```

## 准星预览原理

准星代码是分号分隔的「键;值」文本。`crosshair.js` 解析 P 段（主准星），提取颜色、内线/外线/中心点/描边等参数，用 Canvas 绘制静止预览。

## 自动更新方案（里程碑 2，待做）

- 抓取脚本定期从公开站点（prosettings.net、vcrdb.net 等）抓取职业选手准星
- GitHub Actions 定时运行 → 更新 JSON → GitHub Pages 免费静态托管
- 应用启动时拉取最新数据，内置离线快照兜底
- 无官方实时接口，抓取失败保留上次数据

## 原则

- 小步推进，一次只做一个步骤，做完验证再继续
- 不引入无必要的重依赖
