# 设计规范

## 视觉配色（淡黄色主题）

| 用途 | 色值 |
| --- | --- |
| 主背景 | `#FFF6E5` |
| 卡片 / 头部 / 页脚背景 | `#FFFDF7` |
| 边框 | `#F0DFC0` |
| 主强调色（按钮/选中标签） | `#F0B429` |
| 强调色加深（hover） | `#DE911D` |
| 主文字 | `#3B2F1E` |
| 次要文字 | `#8A7350` |
| 准星预览区背景 | 深色径向渐变 `radial-gradient(#3a4655 → #1a2129)` |

字体：`Segoe UI` / `Microsoft YaHei` / `system-ui`。

## 布局

- 顶部：标题 + 搜索框（右对齐，圆角输入框）
- 标签页：社区准星 / 职业选手准星（胶囊样式，带数量角标）
- 内容：卡片网格（`repeat(auto-fill, minmax(220px, 1fr))`）
- 卡片自上而下：准星预览图 → 名字/ID（在准星下方）→ 复制按钮 → 可展开代码
- 页脚：使用说明

## 交互

- 复制成功：按钮变绿显示「已复制 ✓」，1.5 秒后恢复
- 搜索：即时过滤
- 窗口缩放：准星自动重绘（保持清晰、不变形）

## 原则

简单、直观为主，留白充足，无多余装饰。
