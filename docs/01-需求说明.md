# 需求说明

## 背景

用户（非程序员）想要一个 Windows 桌面软件，收集、展示《无畏契约》（Valorant）准星，方便查找、预览、一键复制代码进游戏使用。

## 已确认决策

| 项目 | 决定 |
| --- | --- |
| 软件形态 | Windows 桌面软件（双击打开） |
| 职业选手更新 | 自动定期更新 |
| 使用范围 | 分享给朋友 / 小圈子 |
| 用户上传 | 不支持，只做展示（数据由我们收集） |

## 功能清单

1. 两个栏目：**社区准星** / **职业选手准星**
2. 准星预览：直观看到准星长什么样
3. 一键复制代码（粘贴到游戏「设置 → 准星 → 导入准星代码」）
4. 职业选手准星下方标注名字 / 代号 ID 与队伍
5. 搜索：按准星名、选手名/ID、队伍即时过滤
6. 淡黄色、简洁直观的 UI

## 非目标（本期不做）

- 用户注册 / 上传 / 审核
- 手机端
- 比赛分秒级实时同步（无官方接口，只能定期抓取更新）
